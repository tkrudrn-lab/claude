# 0a 공용 뼈대 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 모든 도메인 스킬이 공유하는 세 조각 — 경로 설정(`paths.env`), 텔레그램 알림(`notify.py`), 미디어 카탈로그(`catalog.py`) — 를 윈도우에서 지금 만들고 맥에서 그대로 돌게 한다.

**Architecture:** 저장소 `platform/jobs/`에 Python 3 스크립트 3개(`common.py` · `notify.py` · `catalog.py`)와 설정 예시 2개. 실제 설정·토큰은 저장소 밖 `~/.config/hermes/*.env`. 로그는 `~/hermes-logs/<job>.log`에 실행당 1줄이고, 그 줄은 `notify.py`가 쓴다(모든 잡이 알림으로 끝나므로 알림 = 로그 지점). 스케줄(launchd)은 0b.

**Tech Stack:** Python 3.14 (stdlib `urllib`·`csv`·`unittest`), Pillow 12 (설치돼 있음), ffprobe (설치돼 있음, 없으면 영상 필드만 빈칸). pytest·python-dotenv·requests **쓰지 않는다**.

**Spec:** [platform/자동화_설계_v01.md](자동화_설계_v01.md) — "공용 뼈대 (platform)" 절. 설계의 `notify.sh`·`~/hermes-jobs/`는 이 계획에서 `notify.py`·`platform/jobs/`로 확정(같은 턴에 설계 갱신).

## Global Constraints

- Claude API 키 금지. 이 스크립트들은 Claude를 부르지 않는다.
- 토큰·경로 설정은 저장소에 넣지 않는다. `~/.config/hermes/` 만. 예시 파일(`*.env.example`)만 커밋.
- 원본 미디어는 읽기만. 카탈로그는 폴더 안 `_catalog.csv` 하나만 쓴다.
- 경로 값은 2026-10-25 현재 `D:\`·`C:\Users\kk9oo\`. 맥 반입 때 `paths.env` 값만 바꾼다 — 코드에 경로를 박지 않는다.
- 카탈로그 `rel_path`는 `/` 구분자(posix). 맥으로 옮겨도 행이 그대로 유효해야 한다.
- 알림은 실패해도 로그 줄은 남는다. 0건도 보낸다.
- 테스트는 `platform/jobs/`에서 `python -m unittest test_jobs -v`.
- 커밋은 브랜치 `automation-0a`에서. 이 계획의 파일만 `git add` (저장소에 미추적 파일이 많다).

1. 한글·공백 경로 (`D:\서천군 영상 소스\...`) — 카탈로그 행·CSV·로그가 깨지지 않아야 한다. → Task 3 테스트 폴더명을 한글+공백으로.

### Task 2: notify.py — 텔레그램 알림

**Files:**
- Create: `platform/jobs/notify.py`
- Modify: `platform/jobs/test_jobs.py` (TestNotify 추가)

**Interfaces:**
- Consumes: `common.load_env("telegram")` → `TELEGRAM_BOT_TOKEN`·`TELEGRAM_CHAT_ID`; `common.log_line(job, msg)`.
- Produces:
  - 상수 `MAX_FILE_BYTES = 50 * 1024**2`, `MAX_PHOTO_BYTES = 10 * 1024**2`, `MAX_CAPTION = 1024`, `MAX_TEXT = 4096`.
  - `send(text: str, file: Path | str | None = None, job: str = "manual") -> bool`
    - 항상 먼저 `log_line(job, text.splitlines()[0])`.
    - `file` 없음 → `sendMessage` (`text` 는 `MAX_TEXT`로 자름).
    - `file` 있음: 크기 > `MAX_FILE_BYTES` → `sendMessage`로 `text + "\n파일: " + str(file)`. 아니면 확장자(소문자)로 `.jpg .jpeg .png` → `sendPhoto`(단, 크기 > `MAX_PHOTO_BYTES` 면 `sendDocument`), `.mp4 .mov` → `sendVideo`, 그 외 `sendDocument`. 파일 필드명은 각각 `photo`·`video`·`document`. `text` 는 `caption`(`MAX_CAPTION`로 자름).
    - HTTP 호출은 모듈 변수 `urlopen = urllib.request.urlopen` 을 통해서만 (테스트가 바꿔 끼운다). URL은 `f"https://api.telegram.org/bot{token}/{method}"`.
    - 응답 JSON `ok` 가 True면 True. `ok` False 또는 `URLError`/`HTTPError` → stderr에 한 줄(`notify: <method> 실패 — <description|사유>`) 찍고 False. 예외를 밖으로 올리지 않는다.
  - `_multipart(fields: dict[str, str], file_field: str, path: Path) -> tuple[bytes, str]` — stdlib로 `multipart/form-data` 본문과 `Content-Type` 헤더 값. 파일 Content-Type은 `mimetypes.guess_type`, 없으면 `application/octet-stream`.
  - `setup() -> int` — `getUpdates` 호출, 마지막 `message.chat.id`를 `print`. 메시지가 없으면 stderr `"봇에 먼저 아무 메시지나 보내고 다시 실행"` 후 1. 토큰 없으면 `load_env`의 `FileNotFoundError` 메시지 그대로 1.
  - `main(argv: list[str]) -> int` — `--setup` | `--job <job> <text> [--file <path>]`. `send`가 True면 0, False면 1.

```python
import io, json, urllib.error
from contextlib import contextmanager

class FakeTelegram:
    """urlopen 대역. calls 에 (method, body_bytes) 누적."""
    def __init__(self, ok=True, raise_url_error=False):
        self.ok, self.raise_url_error, self.calls = ok, raise_url_error, []
    def __call__(self, req, timeout=None):
        if self.raise_url_error:
            raise urllib.error.URLError("no network")
        self.calls.append((req.full_url.rsplit("/", 1)[1], req.data or b""))
        body = json.dumps({"ok": self.ok, "description": "chat not found", "result": {}}).encode()
        @contextmanager
        def resp():
            yield io.BytesIO(body)
        return resp()

class TestNotify(EnvFixture):
    def setUp(self):
        super().setUp()
        (self.tmp / "cfg" / "telegram.env").write_text(
            "TELEGRAM_BOT_TOKEN=123:abc\nTELEGRAM_CHAT_ID=777\n", encoding="utf-8")
        import notify
        self.notify = notify
        self.fake = FakeTelegram()
        notify.urlopen = self.fake

    def _method(self): return self.fake.calls[-1][0]

    def test_text_uses_sendMessage(self):
        self.assertTrue(self.notify.send("카탈로그 · 비바 +3", job="catalog"))
        self.assertEqual(self._method(), "sendMessage")
        self.assertIn(b"777", self.fake.calls[-1][1])

    def test_jpg_uses_sendPhoto(self):
        p = self.tmp / "썸네일.jpg"; p.write_bytes(b"\xff\xd8\xff" + b"0" * 10)
        self.assertTrue(self.notify.send("제목", file=p, job="blog"))
        self.assertEqual(self._method(), "sendPhoto")
        self.assertIn(b'name="photo"', self.fake.calls[-1][1])
        self.assertIn("제목".encode(), self.fake.calls[-1][1])

    def test_mp4_uses_sendVideo_and_other_uses_sendDocument(self):
        v = self.tmp / "E03.mp4"; v.write_bytes(b"0" * 10)
        d = self.tmp / "buyers.csv"; d.write_bytes(b"0" * 10)
        self.notify.send("릴스", file=v); self.assertEqual(self._method(), "sendVideo")
        self.notify.send("바이어", file=d); self.assertEqual(self._method(), "sendDocument")

    def test_big_file_falls_back_to_text_with_path(self):
        self.notify.MAX_FILE_BYTES = 5
        v = self.tmp / "big.mp4"; v.write_bytes(b"0" * 10)
        self.assertTrue(self.notify.send("렌더 완료", file=v, job="seocheon"))
        self.assertEqual(self._method(), "sendMessage")
        self.assertIn("파일: ".encode(), self.fake.calls[-1][1])

    def test_long_text_truncated(self):
        import urllib.parse
        self.notify.send("가" * 5000)
        form = urllib.parse.parse_qs(self.fake.calls[-1][1].decode())
        self.assertEqual(len(form["text"][0]), 4096)

    def test_api_not_ok_returns_false_and_logs(self):
        self.notify.urlopen = FakeTelegram(ok=False)
        self.assertFalse(self.notify.send("x", job="inbox"))
        self.assertTrue((self.tmp / "logs" / "inbox.log").exists())

    def test_url_error_returns_false_and_logs(self):
        self.notify.urlopen = FakeTelegram(raise_url_error=True)
        self.assertFalse(self.notify.send("x", job="inbox"))
        self.assertEqual(len((self.tmp / "logs" / "inbox.log").read_text(encoding="utf-8").splitlines()), 1)
```

### Task 3: catalog.py — 미디어 카탈로그

**Files:**
- Create: `platform/jobs/catalog.py`
- Modify: `platform/jobs/test_jobs.py` (TestCatalog 추가)

**Interfaces:**
- Consumes: `common.load_env("paths")["HERMES_CATALOG_DIRS"]` (`;` 구분); `notify.send(text, job="catalog")`.
- Produces:
  - 상수 `CATALOG_NAME = "_catalog.csv"`, `COLUMNS = ["rel_path", "taken", "duration_s", "width", "height", "size_mb", "note"]`, `MEDIA_EXT = {".jpg", ".jpeg", ".png", ".gif", ".mov", ".mp4", ".m4v", ".avi", ".mkv", ".webm"}`, `SKIP_DIRS = {"$RECYCLE.BIN", "System Volume Information", "PremiereCache", "_esrgan_work", "_mosaic", "node_modules"}`, `SKIP_MARKER = ".nocatalog"`.
  - `scan(folder: Path) -> list[Path]` — 재귀. 제외: 이름이 `SKIP_DIRS`에 있거나 `.`으로 시작하는 폴더, 안에 `SKIP_MARKER` 파일이 있는 폴더(하위 포함), 확장자(소문자)가 `MEDIA_EXT` 밖인 파일, `CATALOG_NAME`.
  - `probe(path: Path) -> dict[str, str]` — 키 `taken`·`duration_s`·`width`·`height`·`size_mb`. 모두 문자열, 모르면 `""`. **어떤 예외도 밖으로 내지 않는다** — 실패한 필드만 빈칸.
    - 이미지(`.jpg .jpeg .png .gif`): Pillow `Image.open` → `width`·`height`; EXIF `0x8769` IFD의 `0x9003`(DateTimeOriginal) `YYYY:MM:DD HH:MM:SS` → `taken = "YYYY-MM-DD HH:MM:SS"`.
    - 영상: `shutil.which("ffprobe")` 없으면 영상 필드 전부 `""`. 있으면 `ffprobe -v error -select_streams v:0 -show_entries stream=width,height:stream_side_data=rotation:format=duration:format_tags=creation_time -of json <path>` → `duration_s`는 소수 1자리, `rotation` 절댓값 90이면 width/height 교환, `creation_time` ISO → `taken` 앞 19자(`T`→공백).
    - `taken` 못 구하면 파일 mtime을 같은 포맷으로. `size_mb`는 소수 1자리.
  - `update_catalog(folder: Path) -> tuple[int, int]` — 기존 `_catalog.csv`(utf-8-sig) 를 `rel_path`→행 dict로 읽고, `scan` 결과와 비교. 새 파일은 `probe`해서 추가(`note=""`), 사라진 파일 행은 삭제, 남은 행은 `note` 포함 그대로. `rel_path = path.relative_to(folder).as_posix()`. `rel_path` 정렬로 다시 쓴다(utf-8-sig, `COLUMNS` 헤더). 반환 `(added, removed)`. 폴더 없으면 `FileNotFoundError`.
  - `main(argv: list[str]) -> int` — 인자 폴더들, 없으면 `HERMES_CATALOG_DIRS`. 폴더마다 `"{folder.name} +{added} −{removed} ({총행수})"` 출력, 없는 폴더는 `"{folder.name} 없음"`. `--notify`면 `notify.send("카탈로그 · " + " · ".join(줄들), job="catalog")`. 처리한 폴더가 하나도 없으면 1, 아니면 0.
