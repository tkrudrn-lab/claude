## 4. 파일 이사 — 두 단계 (SSD 1TB)

**4a. 지금: 필수만 SSD로.** 서천 영상 소스처럼 큰 건 D:에 두고 꽂아서 읽는다.

```bash
D="/Volumes/My Passport"
cp -R "$D/mac_transfer/hermes" ~/hermes
cp -R "$D/mac_transfer/hidino-reels" ~/hidino-reels
cp -R "$D/mac_transfer/tools" ~/tools
mkdir -p ~/Media ~/.config/hermes ~/hermes-logs
cp -R "$D/비바사진_바탕화면_20261017" ~/Media/          # 블로그·릴스 소스 (작음)
cp -R "$D/하이다이노_릴스" ~/Media/                      # 릴스 산출물
cp -R "$D/nuritech" ~/nuritech                           # 누리텍 작업 폴더 (~1.5GB)
cp -R "$D/mac_transfer/hermes_config/." ~/.config/hermes/
du -sh ~/Media ~/nuritech ~/hermes                       # 합쳐서 수십 GB 수준이어야 정상
```

`~/.config/hermes/paths.env`를 맥 값으로 **통째로 교체** (서천은 D: 경로 — 꽂혀 있을 때만 유효):

```
# hermes 공용 경로 (맥, 1단계). 경로마다 ~ 가 풀린다. 큰 외장하드 오면 이 파일만 고친다.
HERMES_VIVA=~/Media/비바사진_바탕화면_20261017
HERMES_SEOCHEON=/Volumes/My Passport/서천군 영상 소스
HERMES_REELS_OUT=~/Media/하이다이노_릴스
HERMES_NURITECH=~/nuritech
HERMES_REELS_COMP=~/hidino-reels
HERMES_LOGS=~/hermes-logs
# 카탈로그는 쓰기 가능한 폴더만 — 서천은 NTFS 읽기 전용이라 _catalog.csv 를 못 쓴다(기존 CSV 읽기는 됨). 큰 하드로 옮긴 뒤 추가
HERMES_CATALOG_DIRS=~/Media/비바사진_바탕화면_20261017
```

**4b. 큰 외장하드가 오면 (24시간 맥에 상시 연결):** D: 전체를 그 하드로 `rsync -avh --exclude '$RECYCLE.BIN' --exclude 'System Volume Information' --exclude 'PremiereCache' "/Volumes/My Passport/" "/Volumes/<새하드>/"`, `~/Media/`의 두 폴더도 그쪽으로 옮기고 `paths.env`의 경로를 `/Volumes/<새하드>/…`로, `HERMES_CATALOG_DIRS`에 서천 추가. D:는 백업으로 보관. 코드는 안 바뀐다 — 바뀌면 설계가 틀린 것.

`telegram.env`는 노트북 것이 그대로 온다(봇을 아직 안 만들었으면 빈칸 — 6절에서).
