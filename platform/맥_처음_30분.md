# 맥 처음 켠 사람을 위한 30분 — 맥 세팅 1절 풀이판

[맥_세팅_v01.md](맥_세팅_v01.md) 1절(사람 몫)을 맥을 처음 쓰는 사람 기준으로 풀어 쓴 것. 이 파일은 `D:\mac_transfer\`에도 복사돼 있으니 맥에서 Finder → My Passport → mac_transfer → 더블클릭(텍스트 편집기)으로 열어 보면서 해도 된다.

## 0. 맥 키보드 3개만

| 키 | 윈도우로 치면 | 쓰는 데 |
|---|---|---|
| **⌘ command** (스페이스 양옆) | Ctrl | 복사 ⌘C · 붙여넣기 ⌘V · 저장 ⌘S |
| **⌥ option** | Alt | atticus 단축키 등 |
| **⌃ control** | — | 터미널에서 중단 ⌃C |

- **스포트라이트**: `⌘ + 스페이스` → 아무 앱 이름 치고 return. 앱 찾는 가장 빠른 길.
- **return** = 엔터.
- 터미널에서 **비밀번호를 치면 화면에 아무것도 안 보인다.** 정상이다. 그냥 치고 return.

## 1. 시스템 설정 (10분)

화면 왼쪽 위 **** → **시스템 설정**. 왼쪽 위 **검색창**에 항목 이름을 치면 바로 찾아진다. 못 찾으면 검색.

1. **에너지** (검색 "에너지") — 아래 셋을 **켬**
   - 디스플레이가 꺼져 있을 때 자동으로 잠자기 방지
   - 네트워크 접근을 위해 깨우기
   - 정전 후 자동으로 시작
2. **일반 → 공유** — 아래 셋을 **켬**
   - 원격 로그인 (SSH). 켜면 "접근 허용: 모든 사용자"로
   - 화면 공유
   - 파일 공유 → 오른쪽 **ⓘ** → **옵션…** → "Windows 파일 공유" 아래 **본인 계정 체크** → 비밀번호 → 완료
3. **일반 → 정보** → **이름** 칸을 `mac-studio`로
4. **개인정보 보호 및 보안 → FileVault** — "끔"이면 그대로. "켬"이면 **끄기** (해제에 시간이 걸릴 수 있음, 그동안 다른 단계 진행)
5. **사용자 및 그룹** → **자동 로그인** → 본인 계정 선택 → 비밀번호. (FileVault가 켜져 있으면 이 메뉴가 회색이다 → 4번 먼저)
6. 시스템 설정 맨 위 **본인 이름(Apple 계정)** 클릭 → 로그인돼 있는지 확인. 안 돼 있으면 로그인. App Store도 한 번 열어 로그인.

## 2. 터미널 세 줄 (10~20분, 대부분 기다리는 시간)

**터미널 열기**: `⌘ + 스페이스` → `터미널` → return. 검은(또는 흰) 창이 뜬다. 아래 명령은 **한 줄씩** 붙여넣고(⌘V) return.

**① Xcode 도구**
```bash
xcode-select --install
```
팝업이 뜨면 **설치** → 동의 → 5~10분. "이미 설치됨"이라고 나오면 다음으로.

**② Homebrew (맥의 프로그램 설치기)**
브라우저로 <https://brew.sh> 를 열면 맨 위에 `/bin/bash -c "$(curl …)"`로 시작하는 **한 줄**이 있다. 옆의 복사 버튼 → 터미널에 ⌘V → return.
- "Press RETURN/ENTER to continue" → return
- "Password:" → 맥 로그인 비밀번호 (안 보임) → return
- 5~10분 기다림
- 끝에 **"Next steps:"** 아래에 `echo …` 와 `eval …` 로 시작하는 줄 2~3개가 보인다. **그 줄들을 전부 복사해서 붙여넣고 return** (이걸 안 하면 `brew`를 못 찾는다)
- 터미널을 닫았다가(⌘Q) 다시 열고:
```bash
brew --version
```
`Homebrew 4.x.x` 처럼 나오면 성공.

**③ Claude Code 확인**
```bash
claude --version
```
- 버전이 나오면 OK.
- `command not found`면 아직 Claude Code(터미널용)가 아니라 Claude 앱만 깐 것. 이걸 실행:
```bash
curl -fsSL https://claude.ai/install.sh | bash
```
끝나면 터미널 닫고 다시 열어 `claude` → 브라우저가 열리며 로그인 → 터미널로 돌아오면 됨. `/exit` 로 나온다.

Claude **데스크톱 앱**도 있으면 좋다(아이폰에서 맥 세션 이어받기용):
```bash
brew install --cask claude
```
→ 스포트라이트에서 "Claude" 실행 → 로그인.

## 3. 외장하드 꽂기 (1분)

My Passport를 USB로 꽂는다. Finder(독 맨 왼쪽 웃는 얼굴) 왼쪽 목록에 **My Passport**가 뜬다. 터미널에서 확인:
```bash
ls "/Volumes/My Passport/mac_transfer"
```
`claude_skills  hermes  hidino-reels …` 가 보이면 됨. (이 하드는 윈도우 포맷이라 맥에서 **읽기만** 된다. 복사해 오는 건 문제없다.)

## 4. 맥의 Claude에게 넘기기 (여기서부터 자동)

```bash
cd "/Volumes/My Passport/mac_transfer/hermes" && claude
```
처음 한 번 "이 폴더를 신뢰하겠느냐" → **Yes**. 프롬프트가 뜨면 이 문장을 붙여넣고 return:

> `platform/맥_세팅_v01.md` 읽고 2절부터 순서대로. 설치 전에 README·스크립트를 읽고 한 줄로 보고. 실패하면 멈추고 물어.

이후 Claude가 알아서 깔고, **로그인이 필요한 곳에서 멈춰 묻는다**: Tailscale · Parsec · 네이버 · 텔레그램 봇. 그때만 손대면 된다. 막히거나 이상하면 그 메시지를 노트북 쪽 세션에 그대로 붙여 넣으면 된다.

## 자주 막히는 데

- **"Permission denied"나 자물쇠 아이콘**: 시스템 설정 → 개인정보 보호 및 보안에서 터미널/Claude에 권한 허용 → 다시 시도.
- **`brew: command not found`**: 2-② 의 "Next steps" 줄을 안 돌린 것. brew.sh 설치 명령을 다시 돌리면 끝에 다시 보여 준다.
- **한글 폴더명이 깨져 보임**: 터미널 글꼴 문제일 뿐, 파일은 멀쩡하다. Finder로 보면 정상.
- **하드가 안 보임**: 다른 USB 포트(뒤쪽) → 그래도 안 보이면 Finder → 설정 → 사이드바 → "외장 디스크" 체크.
